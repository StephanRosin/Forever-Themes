# Forever Themes

One place to set the look of all your Forever addons, for **WoW: Forever**. English, Deutsch, Español, Français.

The Forever addons (Unit Frames, Quest Log, Combat Meter, Data Bar, Group Finder, Square Minimap) each come with the same set of themes built in. Without Forever Themes, you pick a theme in each addon on its own. With it, you pick once.

## Themes
Classic, Wood, Parchment, Tech, Runestone, Stained Glass, Comic, Frost, Pixel, Swiss Clean, Console and Pitwall, each with its own colour choices: five to nine per theme.

## One theme for everything
- Choose a theme and a colour once, and every Forever addon you have installed follows it.
- **Override per addon**: each addon can follow the central theme (the default) or keep a theme and colour of its own, for example Pitwall everywhere but Wood on the quest log.
- Addons you don't have are simply skipped.

## Blizzard's windows
Forever Themes also dresses Blizzard's own windows in the same theme, each one switched on or off on its own:
- Character
- Spellbook
- Talents
- Professions
- Legacy
- Guild & Communities
- Collections

The skins only change the look: backdrop, rim, title bar, tabs, close button and fonts. They never move, resize, show or hide Blizzard's frames, and switching a skin off (or choosing Classic) puts the window back exactly as it was.

## Blizzard's texts
The theme's font for Blizzard's cast bar, buff timers, error messages and the damage numbers above enemies, and for Platynator nameplates. Each can be switched on or off.

Switch the Platynator font off before you remove Forever Themes: otherwise Platynator keeps the theme's font.

The game reads the font of the damage numbers only when you log in, so after a theme change they follow at your next login; a /reload is not enough.

## Where to find it
- The minimap button: left-click for the options window, right-click for the theme menu. Or type `/forever`.
- The **Theme** element of Forever Data Bar: shows the current theme and colour, left-click for the theme menu, right-click for the options.

## Good to know
- Forever Themes is optional. Every Forever addon works without it, with its own theme setting as before.
- Your current choices carry over: the central theme is the one your Forever addons already wear, and an addon wearing a different one keeps it. The window skins and the font switches start as your Forever addons had them (off where they were off), so nothing changes when you install it. If you have no Forever addon yet, you start with Pitwall in red, every window skin and both font switches on.
- A Forever addon you install later follows the central theme only if it already wears it; otherwise it keeps its own.
- Forever Unit Frames keeps a theme per profile: the central theme goes to the character's active profile, so another profile shows its own theme until you log in with it.
- No effect on performance in combat: themes are applied when you change them, not every frame.
